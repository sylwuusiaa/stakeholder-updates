# Soroban Block Explorer & Stellar Prices API: update, 5–19 Nov 2026

Repositories: [soroban-block-explorer](https://github.com/rumblefishdev/soroban-block-explorer), [stellar-prices-api](https://github.com/rumblefishdev/stellar-prices-api)

## Highlights

- **Moved to the sorobanscan.com domain.** The explorer, the Prices API (`prices-api.sorobanscan.com`), the API portal and the database host (`ch.sorobanscan.com`) now all run on sorobanscan.com. The old addresses redirect to the new ones, and the old domains and DNS setup have been removed. Search Console and Google Analytics are set up for the new domain.
- **More accurate network throughput (TPS).** The explorer now reports TPS as operations per second, including failed transactions. Before, it counted transactions, which is about half the real activity. We checked the new figures against Horizon (Stellar's reference API) and they match exactly.
- **Prices API release.** We released everything built since Milestone 3:
  - pricing fixes: correct token decimals in AMM pools, USD prices taken only from USDC and XLM markets, and prices for history before 2021
  - new Blend and Comet pools tracked
  - support for Stellar protocol 30
  - the API now accepts a classic asset's Soroban contract address (SAC), and we confirmed this works in production for XLM, USDC, AQUA, EURC and others
  - the code repository now matches exactly what runs in production
- **Security.** A back-door API address that skipped our Cloudflare protection is now closed. Lookups of NFT metadata through IPFS (the decentralized file network NFT data is stored on) are more reliable now that they go through Filebase. Monitoring alerts now fire separately for each network.

## Smaller changes

- Small display fixes: very small prices and rates no longer show as 0, event data is easier to read, and large numbers are formatted correctly.
- `sorobanscan.com/api/x402-facilitator/` now leads to the x402 API key portal, which is password-protected for now.
- Both projects are now formally open source under the MIT license.
